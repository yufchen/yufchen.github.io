# Yufeng Chen — personal website

This repository contains the Jekyll source for [yufchen.github.io](https://yufchen.github.io/).

The website source lives in [`website/`](website/). See [`website/README.md`](website/README.md) for editing and local preview instructions.

Pushing to `master` triggers the GitHub Pages workflow in `.github/workflows/pages.yml`, which builds and deploys the site from `website/`.

The published CV is available at the stable path `website/files/cv/yfchen_cv.pdf`.
